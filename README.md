# striblingfilm.com

Redirects to https://www.williamjstribling.com/, which is the canonical site
(built from the `WJStribling.github.io` repo).

GitHub Pages can't do server-side 301s, so this is an instant meta-refresh plus
a JS redirect that preserves the path. Search engines treat that as equivalent
to a permanent redirect.

The `mejorana.striblingfilm.com` subdomain is unaffected; it's served by the
separate `mejorana` repo.
